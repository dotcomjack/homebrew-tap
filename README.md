# dotcomjack tap

Homebrew formulae and casks from [DotcomJack](https://dotcomjack.com).

## grux

The god agent for solopreneurs on Mac. Opens terminal sessions it can undo, runs
agent swarms, builds iOS apps, handles your mail and your meetings.

```sh
brew install --cask dotcomjack/tap/grux
```

Installs `Grux.app` and links its command line as `grux`, so the app and the CLI
arrive together. Signed with a Developer ID, notarized and stapled. Apple silicon,
macOS 14 or later.

Source: https://github.com/dotcomjack/grux (MIT) | https://gruxai.com

## claude-session-tint

Know which of your parallel Claude Code sessions is waiting on you.

```sh
brew install dotcomjack/tap/claude-session-tint
```

Source: https://github.com/dotcomjack/claude-session-tint (MIT)

## nocturne

Stop your macOS menu bar clock from telling you it is 3am.

```sh
brew install --cask dotcomjack/tap/nocturne
```

Signed with a Developer ID, notarized and stapled, so it opens without a
right click. macOS 14 or later.

Source: https://github.com/dotcomjack/nocturne (MIT)
